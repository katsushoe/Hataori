## 変更内容

- **バグ修正**: `.NET`の`Process.Start`（`UseShellExecute=false`）は、拡張子なしのCommand名（例: `codex`）からnpmが生成する`.cmd`／`.ps1`シムを自動解決しない。このため、`agents.codex.executablePath`を既定の`"codex"`のまま使うと、`npm install -g @openai/codex`でインストールした環境（`codex.cmd`のみ存在し`codex.exe`は存在しない）で`hataori doctor`の`codex_cli`チェックが失敗し、かつ**Activation Managerが実際にCodex Agentを起動する際にも同じ経路（`SystemAgentProcessManager`）で同様に失敗する**実害があった。
- `Hataori.Application.ExecutableResolver`を新規実装し、PATH・PATHEXTに基づき拡張子なしCommand名を実在するfile（`.com`/`.exe`/`.bat`/`.cmd`の順）へ解決してから`Process.Start`へ渡すよう、`SystemProcessRunner`（doctorの実行file確認）と`SystemAgentProcessManager`（実際のAgent起動）の両方を修正した。
